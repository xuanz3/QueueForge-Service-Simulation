# QueueForge

QueueForge is a local-first service operations simulator for evaluating queue behaviour and staffing decisions before changing real operations.

The project is being developed phase by phase. Product scope, architecture decisions, simulation contracts, tests, performance evidence and failure recovery will remain traceable through GitHub Issues and Pull Requests.

## Planned technical responsibilities

- **C++20** — deterministic discrete-event simulation engine
- **Python** — repeated experiments, statistics and report generation
- **Java / Spring Boot** — orchestration, lifecycle management and persistence
- **React / TypeScript** — scenario configuration and results visualisation

## Current status

Repository foundation established. Phase 0 defines the product boundary and engineering evidence before implementation begins.
