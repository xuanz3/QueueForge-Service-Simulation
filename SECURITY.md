# Security Policy

## Supported version

Security fixes are considered for the current `v1.x` release line.

## Reporting

Do not publish credentials, private operational data or exploitable details in
a public Issue. Use GitHub's private vulnerability reporting feature when it is
available for the repository.

Include:

- affected version or commit
- reproduction steps
- expected and observed behaviour
- potential impact
- suggested mitigation, when known

## Scope

QueueForge is designed for local demonstration with fictional scenarios. It is
not intended to process confidential operational data or to be exposed
directly to the public internet without additional authentication,
authorization, TLS, secret management and deployment hardening.
