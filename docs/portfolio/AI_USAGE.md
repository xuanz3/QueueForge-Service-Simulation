# AI Assistance Policy

AI-assisted tools may be used for drafting boilerplate, exploring alternatives and checking implementation ideas.

Every accepted change must still be:

- reviewed against the stated requirement
- executed locally or in CI
- covered by appropriate tests
- explained in the corresponding Issue or Pull Request
- traceable to a human-selected design decision

AI output is not accepted as evidence of correctness. Measured results, committed tests and reproducible commands are the evidence.
