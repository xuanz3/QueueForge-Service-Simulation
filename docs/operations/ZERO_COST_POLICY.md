# Zero-Cost Policy

QueueForge must remain reproducible without paid infrastructure.

## Approved categories

- OpenJDK and Spring Boot
- CPython and open-source Python packages
- GCC or Clang, CMake and open-source C++ test tools
- React, TypeScript and open-source web packages
- PostgreSQL
- Local containers
- GitHub public repository features
- Mermaid diagrams
- Generated demonstration data

## Excluded dependencies

- Paid cloud compute
- Paid model APIs
- Commercial datasets
- Paid databases
- Required custom domains
- Paid observability products
- Paid design assets
- Production code-signing certificates

## Design rule

A hosted service may never become necessary to build, test, demonstrate, capture evidence or release the project.
